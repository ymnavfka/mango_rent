# Mango Rent

Офлайн-календарь бронирований для управления объектами аренды.

## Запуск

```sh
flutter pub get
flutter run
```

Для сборки Android APK:

```sh
flutter build apk --release --target-platform android-arm64 --split-per-abi
```

Проект настроен для Android, iOS, macOS, Windows и Linux. Web-платформа не создавалась.

## Возможности первой версии

- Добавление объектов размещения.
- Помесячный календарь с выбором диапазона дат и проверкой пересечений.
- Редактирование дат, статуса, данных клиента, оплаты, гостей, животных, источника и комментария.
- Автоматический подсчёт ночей и сохранение изменений по мере ввода.
- Локальное хранение в SQLite через Drift.

## Структура

- `lib/domain` — сущности и интерфейс репозитория.
- `lib/domain/usecases` — прикладные действия и правила бронирования.
- `lib/data` — Drift/SQLite и реализация репозитория.
- `lib/presentation` — пользовательский интерфейс.
- `lib/main.dart` — точка входа и сборка зависимостей.

Генерация Drift после изменения схемы:

```sh
dart run build_runner build
```
